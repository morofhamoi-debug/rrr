# MORO — язык программирования понятными словами

MORO — экспериментальный русскоязычный язык для создания простых веб-страниц и интерактивных элементов. Его первая версия работает прямо в браузере и не требует установки.

## Запуск

Откройте [демо GitHub Pages](https://morofhamoi-debug.github.io/rrr/) после включения GitHub Pages в настройках репозитория (Settings → Pages → Deploy from a branch → main → /(root)).

Локально достаточно открыть `index.html` в современном браузере.

## Пример программы

```text
Страница
Фон: #f4f5f8

Заголовок
Текст: «Привет!»
Положение: центр

Кнопка (центр)
Текст: «Нажми меня»
При нажатии: показать «Добро пожаловать в MORO!»
```

Можно использовать короткую запись:

```text
Кнопка (центр) текст «Привет» нажатие показать «Ура!»
```

Или открыть ссылку:

```text
Кнопка (центр)
Текст: «Открыть GitHub»
При нажатии: открыть https://github.com/
```

## Поддерживаемые элементы

- `Страница` — начало описания страницы.
- `Фон: #цвет` — цвет фона.
- `Заголовок` — крупный заголовок.
- `Текст` — обычный текст.
- `Кнопка` — интерактивная кнопка.
- `Картинка` — изображение по HTTPS/HTTP адресу.
- `Положение: центр/слева/справа` — выравнивание элемента.
- `Цвет: #цвет` — цвет текста.
- `При нажатии: показать «сообщение»` — показать уведомление.
- `При нажатии: открыть https://адрес` — открыть внешний сайт.

## Архитектура

- `language/interpreter.js` — разбор простого синтаксиса MORO и генерация безопасного HTML-предпросмотра.
- `app.js` — редактор, запуск, примеры и вывод сообщений.
- `style.css` — интерфейс редактора.
- `index.html` — приложение.

## Честно о текущих ограничениях

Это ранний прототип, а не универсальный AI-компилятор. Сейчас он понимает описанные выше конструкции и некоторые варианты короткой записи. Произвольные фразы вроде «сделай сайт красивее» пока не интерпретируются автоматически. Для такого режима позже можно подключить AI-модель и систему уточняющих вопросов.

Код выполняется в изолированном iframe-предпросмотре. Не вводите секреты или пароли в публичные примеры.
