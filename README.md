# VICE CITY — Open World

Браузерный 3D-прототип оригинальной open-world игры в духе криминальных экшенов с открытым городом.

## Запуск
Откройте `index.html` через локальный статический сервер или опубликуйте репозиторий на GitHub Pages.

## Управление
- WASD / стрелки — движение
- Shift — бег
- Space — прыжок
- E — сесть в автомобиль / выйти
- R — вернуть автомобиль
- Удерживайте и двигайте мышь или палец по экрану — камера

## Технологии
Three.js, процедурная геометрия, динамическая камера, тени и HUD. Город генерируется непосредственно в браузере. Никаких экранов загрузки — сцена запускается сразу.
