# LEONIDA — Phase 1

Первая браузерная сборка интерактивного открытого мира: поля, рельеф, трава, асфальтовые и грунтовые дороги, небо и динамический свет. В этой фазе намеренно отсутствуют персонажи, автомобили, здания, животные и городские объекты.

## Запуск через GitHub Pages

Откройте опубликованную страницу репозитория. Для прямого запуска исходников используются import map и Three.js 0.180.0 с jsDelivr CDN; интернет необходим для загрузки библиотеки.

## Локальный запуск и production-сборка

Требуется Node.js 20 или новее.

    npm install
    npm run dev

Production:

    npm run check
    npm run build
    npm run preview

## Управление

- WASD — движение камеры.
- Мышь — поворот (нажмите на сцену для захвата указателя).
- Колесо — приблизить/отдалить.
- E / Q — высота.
- Shift — ускорение.
- T — изменить время суток.
- Esc — открыть меню.

Ландшафт и текстуры создаются процедурно. Рельеф и трава загружаются чанками; трава использует InstancedMesh; чанки имеют несколько уровней детализации; Three.js выполняет frustum culling. Настройки хранятся в localStorage. Это самостоятельная игровая основа, а не готовая AAA-игра: детализация ограничена процедурными материалами и производительностью браузера.
