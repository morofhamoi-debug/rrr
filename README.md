# LEONIDA — Phase 1

Первая браузерная сборка интерактивного открытого мира: поля, рельеф, трава, асфальтовые и грунтовые дороги, небо и динамический свет. В этой фазе намеренно отсутствуют персонажи, автомобили, здания, животные и городские объекты.

Запуск (Node.js 20+):
    npm install
    npm run dev

Production:
    npm run build
    npm run preview

Управление:
- WASD — движение камеры.
- Мышь — поворот (нажмите на сцену для захвата указателя).
- Колесо — приблизить/отдалить.
- E / Q — высота.
- Shift — ускорение.
- T — изменить время суток.
- Esc — открыть меню.

Ландшафт и текстуры создаются процедурно. Рельеф и трава загружаются чанками; трава использует InstancedMesh; Three.js выполняет frustum culling. Настройки хранятся в localStorage. Это самостоятельная игровая основа, а не готовая AAA-игра: детализация ограничена процедурными материалами и производительностью браузера.
